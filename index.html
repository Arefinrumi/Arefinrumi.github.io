01 about // the short version


    

      

        

          I started in a network operations centre watching alarms at 3 a.m., moved into systems and
          data-centre engineering, and now run the platforms themselves. That path is the point: when a
          video stream drops, I don't have to guess whether it's the pipeline, the proxy, the database or
          the firewall — I can go and look at all four.
        

        

          Today I'm responsible for the production infrastructure behind the Convay video-conferencing
          platform and Bangladesh's 333 and DIP national contact-centre services on Oracle Cloud
          Infrastructure. Containerised with Docker, released through Jenkins and GitLab CI with SonarQube
          and Trivy gates, and observed end to end with Prometheus, Grafana, Zabbix and Sentry.
        

        

          The work I'm proudest of tends to be unglamorous: a Galera cluster that came back from a total
          power failure, a nine-playbook Ansible pipeline that turned a multi-day manual build into one
          command, a runbook that means the next person doesn't need me at 3 a.m. either.

Cloudflare Edge HLS Live-Streaming Platform

        
    
          
  • Workers
  • R2
  • D1
  • Durable Objects
  • Load Balancer
  • Owncast
  • Wrangler
    • 
        

        

          Built a token-authenticated HLS delivery path for live and on-demand video: an R2 origin with
          scoped API tokens and explicit CORS and cache rules, a Workers read-through CDN issuing and
          validating per-segment tokens, a steered Load Balancer in front of an Owncast origin, and
          per-viewer bandwidth metering in D1 backed by Durable Objects.
        

        
    
          
  • Cache semantics tuned separately for short-TTL live manifests and immutable media segments.
    • 
          
  • Dashboard-deployed Workers brought back under source control with Wrangler versioning and rollback.
    • 
          
  • Silent metering failures traced to D1 schema drift and closed off.
    •
